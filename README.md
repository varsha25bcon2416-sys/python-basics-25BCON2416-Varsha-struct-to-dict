# Struct to Dictionary

## Description
This program converts a Student dataclass object into a dictionary using Python.

## Features
- Uses a dataclass to define Student details.
- Converts the dataclass object into a dictionary.
- Displays the resulting dictionary.

## Requirements
- Python 3

## How to Run
Run the following command:

python struct-to-dict.py

## Example Output
{'name': 'Aman', 'roll_no': 101, 'course': 'Python'}
